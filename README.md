# ⚡ Tuition Attendance Record

> An offline-first Progressive Web App (PWA) for private tutors to track student attendance, calculate earnings across flexible fee models, generate reports, and back up data — all without any backend or internet connection.

**🌐 Live Demo → [https://attendance-record-nine.vercel.app](https://attendance-record-nine.vercel.app)**

---

## ✨ Key Features

### 🧮 3 Flexible Fee Models
| Model | How Earnings Are Calculated |
|---|---|
| **Per Hour** | Minute-accurate: `(session minutes ÷ 60) × hourly rate` |
| **Per Class** | Flat rate per session, regardless of duration |
| **Fixed Monthly** | One fixed fee charged whenever ≥ 1 class is logged in that month |

### 📶 Offline-First & PWA Support
- All data persists in **IndexedDB** via [Dexie.js](https://dexie.org/) — no server, no account, no cloud dependency.
- **Workbox** service worker (generated by `vite-plugin-pwa`) caches the full app shell so it loads and runs even with no internet.
- Installable on Android & iOS via "Add to Home Screen".

### 📊 Dashboard & Filtered Reports
- Real-time **overall stats**: total students, total classes, cumulative teaching hours, and total earnings.
- **This Month** summary panel with quick at-a-glance metrics.
- **Today's Classes** list sorted by start time.
- **Reports page** with date-range presets (`Today`, `This Month`, `All Time`) and a custom date picker, per-student summaries, full attendance log with inline **Edit** and **Delete**, and **XLSX export** (two-sheet: detail + student summary).

### 💾 Backup, Restore & History Import
- **Full JSON backup**: exports `{ app, version, exportedAt, students, attendance }` as `attendance-backup-YYYY-MM-DD.json`.
- **Restore modes**: upload the JSON backup and choose **Replace** (wipe & restore) or **Merge** (deduplicate by name, skip duplicate sessions). Old `studentId` references are remapped to new Dexie IDs automatically — no orphaned records.
- **History Report import**: upload any `.xlsx`, `.xls`, or `.csv` previously exported from the Reports page. Columns are matched case-insensitively (`Student` / `Student Name` / `Name`, `Start Time` / `Start`, etc.), dates normalised (ISO, DD/MM/YYYY, Excel serial numbers), and exact duplicate sessions skipped.

### 📱 Responsive Mobile-First UI
- **Desktop (> 768 px)**: fixed 240 px left sidebar with brand, offline badge, and nav links.
- **Mobile (≤ 768 px)**: fixed bottom navigation bar with 5 equal-width icon+label tabs. Active tab highlighted in blue (`#2563eb / #eff6ff`).
- Main content area automatically offsets (`margin-left: 240px` / `padding-bottom: 84px`) so nothing hides behind the nav.

## 🗄 Data Model

All data lives in an **IndexedDB** database named `AttendanceRecordDB` (Dexie v2 schema).

### `students` store
| Field | Type | Description |
|---|---|---|
| `id` | auto-increment | Primary key |
| `name` | string | Student's full name |
| `className` | string | e.g. "Class 7" |
| `paymentType` | `"hourly"` \| `"daily"` \| `"monthly"` | Fee model |
| `paymentAmount` | number | Rate in ₹ |
| `hourlyRate` | number | Mirror of `paymentAmount` when type is `hourly` (backward-compat) |
| `createdAt` | ISO string | Record creation timestamp |

### `attendance` store
| Field | Type | Description |
|---|---|---|
| `id` | auto-increment | Primary key |
| `studentId` | number | FK → `students.id` |
| `date` | `YYYY-MM-DD` | Class date (local timezone) |
| `startTime` | `HH:MM` | Session start |
| `endTime` | `HH:MM` | Session end |

### `downloads` store
| Field | Type | Description |
|---|---|---|
| `id` | auto-increment | Primary key |
| `fileName` | string | XLSX filename |
| `createdAt` | ISO string | Export timestamp |
| `fromDate` / `toDate` | string | Date range of the export |
| `studentName` | string | Filtered student or "All Students" |
| `recordsCount` | number | Sessions included |
| `totalHours` | string | Total teaching hours |
| `totalEarning` | string | Total earnings in ₹ |
| `reportData` | JSON string | Raw export rows (for in-app report viewer) |

## 🚀 Local Setup

### Prerequisites
- **Node.js** ≥ 18 and **npm** ≥ 9

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/your-username/attendance-record-app.git
cd attendance-record-app

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
# → http://localhost:5173

# 4. Build for production
npm run build

# 5. Preview the production build locally
npm run preview
```

### Available Scripts
| Command | Description |
|---|---|
| `npm run dev` | Start Vite dev server with HMR |
| `npm run build` | Production build to `dist/` (includes PWA assets) |
| `npm run preview` | Serve the `dist/` folder locally |
| `npm run lint` | Run oxlint on the source |

## 🔒 Data Privacy

> **All your data stays on your device — always.**

This app has **no backend, no database server, no analytics, and no network requests** related to your data. Every student record and attendance session is stored exclusively in your browser's **IndexedDB** via Dexie.js. Nothing is ever transmitted or synced to any external server.

To move data between devices, use the **Backup & Restore** feature on the Export page to download a `.json` file and upload it on another device.
